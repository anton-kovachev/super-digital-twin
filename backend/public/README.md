# Public Folder

This folder contains static files that are served by the Gradio application.

## Security

- Only files in this folder are accessible via the web interface
- The app is configured with `allowed_paths=[str(PUBLIC_DIR)]` for security
- Do not place sensitive files here

- `cv_version_1.pdf` - Alternative CV file
